# 月月直播间模拟器

一个 480×640 的竖屏 H5 叙事小游戏。三天直播，六个结局。

> 本作含精神健康相关描写，仅为虚构叙事。

## 玩

直接打开 `index.html`，或者访问 Pages 地址。

**手机上建议横屏?** 不用，这是竖屏游戏，直接竖着玩。

## 玩法

你是「月」，一个没什么人看的虚拟主播。屏幕里那个比你好看、比你松弛的形象叫「戏中人」。

三天直播，每天定一个关注度目标。弹幕会飘出来，下面四个按钮对应四种回应——接对了涨关注，接错了掉关注，漏接了掉更多。

三条数值：

- **关注度**：成绩。达标才可能有好结局。
- **精神**：本钱。每秒都在掉，归零当场结束。
- **健康**：本钱。唱歌、整活、屏蔽都会消耗。

两套独立干扰：

- **抢麦**（红色面板盖住屏幕）：3.2 秒内按屏蔽，否则他替你播 3 秒，精神 −22。
- **抢按钮**：四个按钮里有一个变成青色的「**我来吧。**」，那是他在跟你说话。按下去关注 +220、精神 −16，还会记一次「让位」。

## 六个结局

| 结局 | 条件 |
|---|---|
| 空 壳 | 精神归零 |
| 断 线 | 健康归零 |
| 谢 幕 | 累计「我来吧。」3 次（压过一切非死亡结局） |
| 共 存 | 关注 ≥ 3400，且精神 ≥ 40 |
| 失 衡 | 关注 ≥ 3400，但精神 < 40 |
| 无人问津 | 三天结束，关注不足 3400 |

## 技术

没有任何依赖、没有构建产物以外的文件、不联网、不存储。整个游戏就是一个 HTML：

- 原生 ES Module 源码，打包成单文件经典脚本
- Canvas 2D 渲染，960×1280 内部分辨率（2x）
- 立绘以内联 base64 WebP 的形式塞在 HTML 里
- 体积约 207 KB
